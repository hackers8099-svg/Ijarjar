# Ijar Jar 🎬

Android video editor (sida CapCut) oo Soomaali ah. APK-ga waxaa si toos ah u dhisa **GitHub Actions** — fiiri **Releases** ama **Actions → Artifacts**.

## Waxyaabaha uu qabto
- **Isku xirka layer-ada (🔗 Isku xir):** dooro laba layer ama ka badan — markaad mid dhaqaajiso, weyneyso, ama wareejiso, kuwa kale way la socdaan. Timeline-kana hal mar ayay ku wada dhaqaaqaan.
- Muuqaalo iyo sawiro badan oo isku xiga (main track)
- Kala jar (split), gooy (trim), nuqul, isku beddel meelaha
- Xawaare (0.25x – 4x), codka (0–200%), aamusi
- Filter-ro (Madow-Cadaan, Sepia, Qadiim, Qabow, Kulul…) + iftiin / contrast / saturation
- Qoraal: midab, xariiq (outline), gadaal, farta, cabbir, toosin
- Sticker-ro (emoji)
- Overlay: sawir ama muuqaal dusha saaran (picture-in-picture)
- Muusik gadaal ah oo cod iyo meel bilow leh
- Saamiga: 9:16, 16:9, 1:1, 4:5, 4:3, 3:4
- Undo / Redo, keydin toos ah
- Dhoofin MP4 (720p / 1080p) → Gallery: Movies/IjarJar

## Build
`gradle :app:assembleRelease` (Gradle 8.7, JDK 17). APK-gu wuxuu ku saxiixan yahay `app/ijarjar.keystore`, sidaas darteed nooc cusub wuu ku dul rakibmayaa kii hore.
